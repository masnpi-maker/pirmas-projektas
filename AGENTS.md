# Project instructions

- Read `context.md` before changing project code; treat current source as authoritative when documentation differs. Update `context.md` when implementation changes materially.
- Use React 19, Vite 8, JavaScript/JSX, and plain CSS. Do not add dependencies or change the stack unless requested.
- Preserve the existing APIs and inspect their current usage before changing endpoints or response handling: Frankfurter for fiat rates and CoinGecko for crypto prices.
- Keep UI copy in Lithuanian, maintain the existing responsive dark/plum/pink design, and preserve accessibility labels and live/error announcements.
- Follow existing style: functional components and hooks, no semicolons, single quotes, two-space indentation.
- Avoid unrelated refactors. Do not add or run tests unless asked.
- `src/AGENTS.md` contains additional instructions scoped to `src/`.
